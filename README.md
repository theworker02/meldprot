# meldprot

Meld timestamps and prot durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/meldprot/

## Install / run

```bash
git clone https://github.com/theworker02/meldprot.git
cd meldprot
node src/cli.js
node --test
```
